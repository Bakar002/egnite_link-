## General Style Guidelines for All Images

### Color Palette:
- **Primary Background:** Black (#000000) to Dark Navy (#000b13, #020304)
- **Accent Colors:** Cyan (#00AEEF, #22D3EE) and Blue (#0066CC, #2563EB)
- **Text/Labels:** White or Light Gray (if text needed)
- **High Contrast:** Dark backgrounds with bright accents

### Style Characteristics:
- **Professional:** High-end, executive-level aesthetic
- **Minimal:** Clean, uncluttered, focused
- **Modern:** Contemporary design language
- **Technical:** Architecture/system-focused, not marketing-heavy
- **Elegant:** Sophisticated, premium feel
- **Abstract:** Conceptual rather than literal
- **Systems-Oriented:** Infrastructure > features, systems > humans

### Technical Specifications:
- **Format:** PNG with transparency preferred (for overlays)
- **Quality:** High resolution (2x for retina displays)
- **Style:** Professional 3D render, vector illustration, or high-end photography
- **Mood:** Authoritative, trustworthy, infrastructure-grade
- **Avoid:** Stock photo clichés, generic AI imagery, human figures, marketing fluff

### Image Generation Tips:
1. Use negative prompts: "no text, no human figures, no stock photo, no generic, no cliché"
2. Emphasize: "professional, technical, architectural, minimal, elegant"
3. Request: "high contrast, dark theme, cyan blue accents, systems architecture"
4. Style modifiers: "photorealistic rendering, professional 3D, technical diagram, architectural visualization"

## Usage Instructions

1. Copy the prompt for the desired image
2. Use with image generation tools (Midjourney, DALL-E, Stable Diffusion, etc.)
3. Adjust dimensions as specified
4. Generate multiple variations and select the best match
5. Ensure images match the dark theme and cyan/blue color palette
6. Export as PNG with transparency if needed for overlays
7. Optimize file size while maintaining quality
8. Place images in: `e-gnite-link/src/assets/images/`
9. Update the component file to reference the actual image paths
